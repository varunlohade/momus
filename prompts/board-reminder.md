# Momus board reminder

Schedule: whatever suits the team (the example team uses 1:30 pm and a
5:30 pm follow-up).

A pattern for nudging people about due work on any board (Notion, Linear,
GitHub Projects). The example below reminds designers about today's social
posts.

1. Query the board for items due TODAY of the type you care about. Filter
   hard: include only that type, not rows with an empty type.
2. Items found → post in the team channel, tagging each assignee by Slack
   handle, asking them to move the item to "Needs review". Map board users to
   Slack users by email. No assignee → say "no owner yet", tag no one.
3. Nothing due → post one plain line, no tags: "Nothing is scheduled for
   today. Let's come up with something."
4. Never tag the owner. Never change an item's status yourself. Never post
   twice on the same day.
5. Repeating nudge for one item: stop the schedule as soon as the item
   moves, and stop for the day after working hours.
