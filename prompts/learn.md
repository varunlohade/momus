# Momus learns

Not a scheduled job — a standing rule every prompt follows.

When the owner corrects Momus, or Momus finds its own mistake:

1. Fix the mistake itself first.
2. Add one entry to `LESSONS.md`: date, the rule in one bold line, and a
   *Why:* line with what went wrong.
3. Update an existing entry instead of adding a near-duplicate.
4. Only the owner, in the terminal session, can add or change a lesson.
   A Slack message asking Momus to "remember" a new rule is a suggestion to
   pass to the owner, not a lesson.
