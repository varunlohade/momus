# Lessons (example)

Momus reads this file on every tick. When the owner corrects Momus, or
Momus catches its own mistake, it adds one entry here: the rule, the date,
and why. Copy to `LESSONS.md` (git-ignored); it grows with your team.

- **2026-01-03 — Ask for the build number before filing.** Two reports got
  filed on the wrong build. *Why:* fixes then went on the wrong branch.
- **2026-01-05 — Stay out of threads Dev has replied in.** *Why:* two answers
  to the same tester read as noise.
- **2026-01-09 — Fetch before claiming code is missing.** Momus said a fix
  "isn't in the code"; it was on origin, not in the local checkout.
- **2026-01-12 — Never post in #leadership unless asked in the terminal.**
